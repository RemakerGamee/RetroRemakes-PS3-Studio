# Online updates - RetroRemakes PS3 Studio (Public Edition)

RetroRemakes PS3 Studio is a RetroRemakes product.

Studio updates are published by RetroRemakes. When this edition has an update channel, the **Online updates** tab checks it, downloads the package, verifies its size and SHA-256, and installs it on the next restart. Previous application files are backed up first. Your `workspace` folder (projects, settings, builds, logs) is never touched.

If the Online updates tab says no update channel is set, download new releases from the RetroRemakes release page and extract them over your Studio folder, keeping your `workspace` folder.
